# Project Board Plan

Create one GitHub Project linked to this repository.

## Columns

1. Backlog
2. Ready
3. In progress
4. Review
5. Integration testing
6. Done

## Required issue fields

- Owner
- Reviewer
- Project phase
- Required output
- Acceptance criteria
- Test ID, when applicable
- Evidence filename
- Dependency or blocker
- Target date
